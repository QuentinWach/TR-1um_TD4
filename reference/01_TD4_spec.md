# TD4 仕様 — 『CPUの創りかた』(渡波郁, マイナビ) の 4bit CPU

## 1. 全体像

| 項目 | 値 |
|---|---|
| データ幅 | **4 bit** |
| 命令語長 | **8 bit**（オペコード 4bit + 即値 4bit） |
| プログラムメモリ | **16 word × 8 bit = 128 bit**（原典は DIPスイッチ 16連 + 74HC154 デコーダ） |
| 汎用レジスタ | **A / B**（各 4bit） |
| 出力レジスタ | **OUT**（4bit、LED） |
| 入力ポート | **IN**（4bit、DIPスイッチ） |
| プログラムカウンタ | **PC 4bit**（0–15、ラップアラウンド） |
| フラグ | **C（キャリー）1bit のみ** |
| 演算器 | **4bit 全加算器 1個**（加算のみ。減算・論理演算なし） |
| 実行方式 | **1命令 = 1クロック（CPI = 1）**、パイプラインなし |
| クロック | 原典は 1 Hz / 10 Hz 手動切替（555 + 手動パルス） |
| スタック / 割り込み / サブルーチン | **無し** |

TD4 は「レジスタ4本 + 加算器1個 + 4→16 デコーダ」という、
**マイクロプロセッサとして考えうるほぼ最小の構成**。
Intel 4004 と比べると、スタック・インデックスレジスタ16本・BCD命令・
2相クロック・双方向バス — これらが **すべて無い**。

## 2. 命令セット（全12命令）

オペコード上位2bit = **書き込み先**、下位2bit = **セレクタ（加算器の A 入力）**。

- `op[3:2]`: `00`→A, `01`→B, `10`→OUT, `11`→PC(ジャンプ)
- `op[1:0]`: `00`→A, `01`→B, `10`→IN, `11`→0
  （ただし `op[3:2]==11` のジャンプ群ではセレクタは強制的に 0）

| ニーモニック | オペコード | 動作 |
|---|---|---|
| `ADD A,Im` | `0000` | A ← A + Im |
| `MOV A,B`  | `0001` | A ← B + 0 |
| `IN  A`    | `0010` | A ← IN + 0 |
| `MOV A,Im` | `0011` | A ← 0 + Im |
| `MOV B,A`  | `0100` | B ← A + 0 |
| `ADD B,Im` | `0101` | B ← B + Im |
| `IN  B`    | `0110` | B ← IN + 0 |
| `MOV B,Im` | `0111` | B ← 0 + Im |
| `OUT B`    | `1001` | OUT ← B + 0 |
| `OUT Im`   | `1011` | OUT ← 0 + Im |
| `JNC Im`   | `1110` | C=0 なら PC ← Im（C=1 なら PC ← PC+1） |
| `JMP Im`   | `1111` | PC ← Im |

未使用: `1000` / `1010` / `1100` / `1101`（原典では OUT 系の重複・NOP 相当）

**キャリーフラグ C は毎クロック加算器のキャリー出力で無条件に更新される。**
したがって `ADD` 以外の命令の直後は必ず C=0 になり、
`ADD` → `JNC` の2命令だけが意味のあるループ構造を作る。

## 3. 原典のハードウェア構成（74HCxx）

| IC | 個数 | 役割 |
|---|---|---|
| 74HC161 | 4 | A / B / OUT レジスタ + PC（同期ロード付きカウンタ） |
| 74HC153 | 2 | 4bit×4入力セレクタ（A / B / IN / 0） |
| 74HC283 | 1 | 4bit 全加算器 |
| 74HC154 | 1 | 4→16 デコーダ（ROM = DIPスイッチのアドレス選択） |
| 74HC14  | 1 | シュミット（クロック整形） |
| 74HC00 / 74HC32 / 74HC540 等 | 数個 | 命令デコーダ（ロード信号生成）、バッファ |
| 555 | 1 | クロック発振 |

**合計 12個前後の IC**。ゲート数にすると 150–200 ゲート規模。

## 4. RTL 化した場合の規模（実測）

本リポジトリ `hdl/rtl/td4_core.v` を Yosys で合成（`abc -g simple`）した結果:

```
FF              : 17   (A4 + B4 + OUT4 + PC4 + C1)
combinational   : 66   (AND 33 / OR 13 / XOR 10 / NOT 6 / MUX 4)
NAND2 equiv     : 180 gates
```

Intel 4004 の **FF 231 / 組合せ 576 / 2,085 ゲート** に対し **約 1/12**。
