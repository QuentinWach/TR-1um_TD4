# TD4 on TR-1um — 設計方針

更新: 2026-09-08

## 0. 結論

**TD4 は TR-1um に「そのまま」載る。** C4004 で必要だった
（① レジスタアレイのカスタム化 ② DFFE カスタムセル ③ 最小サイズセル化 ④ GIO 自作）
の **どれも必須ではない**。既存 STDLIB だけでコア面積の 8–10%。

したがって設計方針は「面積を削る」ではなく **「何を追加で載せるか / どこまで作り込むか」** になる。

## 1. 構成の選択

| 案 | 構成 | 面積 | ピン | リスク | 推奨度 |
|---|---|---:|---:|---|---|
| A | コア + 書換可能プログラムメモリ(128bit FF) | 2.69 mm² | 14 | メモリで面積 NG（要アレイ化） | △ |
| **A″** | `td4_soc_arr` — 同上、**命令メモリのみ 12T RFCELL アレイ化** | **0.81 mm²**（配置後 1.15） | 14 | アレイ設計が1個 | **◎ 本命** |
| B | コア + マスクROM（プログラム固定） | 0.26 mm² | 10–14 | ほぼ無し | ○ 保険 |
| C | コア単体（メモリ外付け） | 0.33 mm² | 22→NG | 双方向バス必須 | ✕ |

### 推奨: **A″ を本命、B を同一チップに同居させる**

面積に 2 mm² 以上の余りがあるので、
**「書換可能メモリ版 TD4」と「マスクROM版 TD4」を1チップに両方載せる**ことができる。
マスクROM版が動けばコアの正しさが確定し、書換版のデバッグが切り分けられる。
さらに余った領域は **セル特性評価 TEG**（リングオシレータ / DFF セットアップ測定 /
RFCELL 単体アレイ）に充てる。これは C4004 に進む前の **セル実証**として価値が高い。

## 2. クロック / リセット

- **単相クロック**。`always @(posedge CLK or negedge RSTN)` のみ。
- TD4 は CPI=1 でステートマシンが無いので、C4004 のような 8ステートカウンタも不要。
- `CLK` / `RSTN` の入力バッファは **シュミットトリガ**にする（原典が 74HC14 を使うのと同じ理由）。
- リセットは非同期 assert / 同期 deassert。メモリ 128bit も RSTN で 0 クリアする。

## 3. RTL 記述ルール

1. `inout` はトップのみ。ただし案A/Bでは **inout を一切使わない**。
2. FF は必ず `posedge CLK` + `negedge RSTN`。ゲーテッドクロックは使わない
   （面積に余裕があるので ICG を作る動機が無い）。
3. 命令メモリ `td4_mem`（16w×8b）は **ブラックボックス化**しておき、
   合成時は FF 実装、実装時はカスタムアレイに差し替えられるようにする
   （実装済み: `hdl/rtl/td4_mem.v` + `td4_soc_arr.v`、設計は `07_memory_array.md`）。
   ・**リードは非同期**（CPI=1 なので PC から組合せで命令が出ること）
   ・**ライトは 8bit 一括**（下位ニブルはステージングレジスタに溜める）
   ・**メモリにリセットを持たせない**（セルごとのクリアTrを省く / リセットで
     プログラムが消えないという副次的な利点もある）
4. セレクタ・加算器はベタ書き（`+` を使う）。abc に任せてよい規模。
5. 出力は必ずレジスタ出力（`OUT[3:0]` は OUT レジスタ直、`CF` はフラグFF直）。

| 段階 | ツール | 内容 |

| 回路 | ngspice | クリティカルパス（セレクタ→加算器→FF）と I/O ドライバのみ |

## 5. 自作が必要なセル

| セル | 必須度 | 備考 |
|---|---|---|
| `IBUF`（シュミット付き） | **必須** | PDK は ESD のみ。`CLK`/`RSTN` 用 |
| `OBUF` | **必須** | LED 駆動を想定するなら数 mA |
| `RFCELL`（**ラッチ型12T・ratioless**） | 案A″で必須 | 帰還TG付きで比設計不要。回路・アレイ構成は `07_memory_array.md` |
| `DFFE`（TG型22T） | 不要 | 面積に余裕があるので DFFR+MUX2 のままでよい |
| `DLATCH` / `ICG` / `GIO` | **不要** | TD4 では出番が無い |

→ **自作セルは実質 IBUF / OBUF の2個（+ 案A″なら RFCELL アレイ）だけ。**

## 6. LEF / Liberty

面積に余裕があるので **自動 P&R を使わず手配置**でも十分現実的
（180 ゲート ≒ 83セル。行高 62.6 µm、総セル幅 5,237 µm → 1行 1,840 µm なら 3行）。

- 案B（マスクROM版・83セル）は **フルカスタム手配置が最短ルート**。
- 案A″（685セル相当）は P&R を使いたい → `lef/` に `tr1um_stdcell.lef` / `.lib` を整備。
  C4004 と共通なので、ここでの整備がそのまま C4004 に効く。

## 7. C4004 への位置づけ

TD4 は **C4004 の前段テストベヒクル**として最適:

| C4004 で必要になるもの | TD4 で先に検証できるか |
|---|---|
| STDLIB の実シリコン動作確認 | **○**（コアがそのまま実証） |
| IBUF / OBUF | **○**（同じセルを使う） |
| RFCELL アレイ | **○**（案A″の 128bit で実証。C4004 は 112bit なのでほぼ同規模） |
| LEF / Liberty と P&R フロー | **○**（案A″で通せば C4004 でも通る） |
| GIO（3ステート双方向） | ✕（TD4 では不要 → TEG として別途載せる価値あり） |
| DFFE / DLATCH カスタムセル | ✕（TD4 では不要 → TEG として載せる） |

→ **空き領域の TEG に GIO と TG-DFFE と RFCELL を載せておけば、
TD4 チップ1個で C4004 に必要なカスタムセルをほぼ全部実証できる。**
