# ピン割当 / I/O 計画 — TD4 on TR-1um

## 1. 制約

`OSS_FRAME` のパッドは **合計16個 = 信号14 + VDD 1 + VSS 1**（各辺4個）。
PDK には **ESD セルしか無い**ので、入力バッファ・出力ドライバは自作が必要。

> **TD4 の最大の利点: 双方向バスが不要。**
> Intel 4004 は D0–D3 が双方向で 3ステート出力ドライバ（GIO）の自作が必須だったが、
> TD4 は入力ポートと出力ポートが物理的に別なので、**入力バッファと出力ドライバだけで済む**。
> GIO（3ステート + 入力段 + oe 制御）を作らなくてよいのは工数・リスクの両面で大きい。

## 2. 案A — `td4_soc_ff`（書換可能プログラムメモリ内蔵）★推奨

チップ単体でプログラムを書き込んで走らせられる。tt-td4 と同じ考え方。

| # | 信号 | 方向 | Load モード (EXEC=0) | Exec モード (EXEC=1) |
|---:|---|---|---|---|
| 1 | `CLK` | in | 書込クロック | 命令実行クロック |
| 2 | `RSTN` | in | 非同期リセット（メモリ・全レジスタ 0 クリア） | 同左 |
| 3 | `EXEC` | in | 0 | 1 |
| 4 | `WR` | in | 書込ストローブ | — |
| 5 | `NIBSEL` | in | 0=下位(即値) / 1=上位(オペコード) ニブル | — |
| 6–9 | `D[3:0]` | in | 命令ニブル入力 | **IN ポート** |
| 10–13 | `OUT[3:0]` | out | — | **OUT レジスタ（LED）** |
| 14 | `CF` | out | — | キャリーフラグ観測 |

**合計 14 信号 = ちょうど一杯。すべて単方向。**

書込アドレスは内部の `ld_addr` が自動インクリメント（上位ニブル書込時に +1）するので、
アドレスピンは不要。RSTN で `ld_addr=0` に戻して先頭から 16命令 × 2ニブル = 32回書けばよい。

### 案A' — ピンを1本空ける
`WR` と `NIBSEL` を統合し、`WR` の立ち上がり毎に内部トグルで 下位→上位→アドレス+1 と回せば
**13信号**になり、1本を `PC[0]` 等のデバッグ出力または予備に回せる。

## 3. 案B — `td4_soc_rom`（マスクROM内蔵）

プログラムは GDS に焼き込み。最小・最も確実。

| # | 信号 | 方向 | 内容 |
|---:|---|---|---|
| 1 | `CLK` | in | クロック |
| 2 | `RSTN` | in | リセット |
| 3–6 | `IN[3:0]` | in | 入力ポート |
| 7–10 | `OUT[3:0]` | out | 出力レジスタ |
| 11–14 | `PC[3:0]` | out | プログラムカウンタ観測（デバッグ用） |

**合計 14 信号**。`PC[3:0]` を出さなければ 10信号で済み、**4本を TEG に回せる**。

## 4. 案C — `td4_core`（命令メモリ外付け）

`rom_data[7:0]` + `rom_addr[3:0]` + `IN[4]` + `OUT[4]` + `CLK` + `RSTN` = **22 信号 → 収まらない**。
4bit バス多重化（アドレス出力とデータ入力を双方向 D[3:0] で共用、CPI=2）にすれば
`CLK` `RSTN` `D[3:0]`(双方向) `IN[4]` `OUT[4]` `ALE` = 14 で収まるが、
**双方向バス = GIO 自作が必要**になり TD4 の利点を捨てることになる。**非推奨**。

## 5. 自作が必要な I/O セル

| セル | 用途 | 備考 |
|---|---|---|
| `IBUF` | 入力バッファ（シュミット推奨） | ESD パッド → 内部。`CLK`/`RSTN` にはシュミット必須 |
| `OBUF` | 出力ドライバ | LED 直結を想定するなら数 mA 駆動。W を大きく取る |
| ~~`GIO`~~ | 双方向 | **案A / 案B では不要** |

## 6. パッド物理配置（各辺4個）

`OSS_FRAME` はパッドが原点から ±200 / ±600 µm、辺の中心線 ±1,040 µm に固定配置。
案A の推奨割当（配線長を短くする方針）:

| 辺 | パッド |
|---|---|
| 上 | `VDD` / `CLK` / `RSTN` / `EXEC` |
| 右 | `WR` / `NIBSEL` / `D[3]` / `D[2]` |
| 下 | `D[1]` / `D[0]` / `CF` / `VSS` |
| 左 | `OUT[3]` / `OUT[2]` / `OUT[1]` / `OUT[0]` |

`OUT[3:0]` を1辺にまとめると出力ドライバ列を1箇所に置けて電源分離しやすい。
