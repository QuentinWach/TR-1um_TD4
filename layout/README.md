# layout/ — レイアウト

```
layout/
├── (magic|klayout) 作業ファイル
└── gds/   中間 GDS
```

- 最終提出物は `../src/<top_cell>.gds`（トップ 2,500×2,500 µm、
  `OSS_FRAME` / `OSS_FRAME_TEG` を含むこと）
- 有効コア領域: 約 1,840 × 1,840 µm（四隅の `OSS_FRAME_CNR` 360×360 µm を避けること）
- 配線層は **M1 / M2 の2層のみ**。M1 pitch 3.2 µm / M2 pitch 5.0 µm。
- DRC/LVS: PDK 付属 KLayout ランセット
  （`TR-1um/libs.tech/klayout/tech/drc/run.drc`, `.../lvs/run.lvs`）

## TD4 のレイアウト規模

| 構成 | セル数 | 総セル幅 | 行高 62.6 µm での行数（1行 1,840 µm） |
|---|---:|---:|---:|
| `td4_soc_rom`（マスクROM版） | 76 | 4,133 µm | **3 行**（= 188 µm 高） |
| `td4_core`（コアのみ） | 83 | 5,237 µm | **3 行** |
| `td4_soc_ff`（書換メモリ版・FF実装） | 685 | 42,986 µm | 24 行（= 1,502 µm 高） |

- **マスクROM版は 3行に収まる**ので、自動 P&R を使わず **手配置が最短ルート**。
- 書換メモリ版はメモリ 128bit を **RFCELL アレイ**（`../reference/06_design_policy.md` §5）
  にすると論理部が約 300セル / 8行程度になり、アレイは別ブロックとして矩形配置できる。

## 空き領域の使い方

コア 3.386 mm² に対し実装面積は 0.2–1.1 mm²。**2 mm² 以上が空く**ので、
C4004 で必要になるカスタムセルの **TEG** を同居させる:

- `GIO`（3ステート双方向 I/O）— C4004 の D0–D3 用。TD4 本体では使わないので TEG でのみ実証
- `DFFE`（TG型 22T）/ `DLATCH`（TG型 8–10T）
- `RFCELL` 単体アレイ（読み書きマージン測定）
- リングオシレータ（INV / NAND2、段数違い）でプロセス実速度を実測

## 自作が必要なセル

`IBUF`（シュミット付き）/ `OBUF`（LED駆動）。
**`GIO` は TD4 本体では不要**（入力ポートと出力ポートが物理的に別のため）。
